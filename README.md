❤️ Heart Rush – Dice Game

Heart Rush is a fun browser-based dice game built using HTML, CSS, and JavaScript.
Roll the dice, feel the rush, and let the game decide the winner

🎮 How to Play

Open the game in your browser

Click the Roll Dice button

The dice rolls for the players

The game announces the winner with sound effects 🎉

Refresh or replay to try again

✨ Features

🎲 Dice-based gameplay

🔊 Sound effects for dice roll & winning

❤️ Winner announcement screen

💻 Runs directly in the browser

🧠 Beginner-friendly JavaScript logic

🛠️ Built With

HTML – Structure

CSS – Styling

JavaScript – Game logic
